🎨 Random Color Generator

A simple and interactive Random Color Generator built using HTML and JavaScript. This project generates a new random color with a single click and displays the corresponding color code in real time. It’s a great beginner-friendly project to understand DOM manipulation, events, and random functions in JavaScript.

🚀 Features

Generates a random color on each click

Displays the HEX color code

Real-time background color change

Simple, clean, and responsive UI

Beginner-friendly logic

🛠️ Tech Stack

HTML – Structure

CSS – Styling (if used)

JavaScript – Random color logic & DOM manipulation

▶️ How to Use

Open the project in your browser

Click the Generate Color button

A new random color will appear instantly along with its code

Copy and use the color anywhere you like!

🎯 Project Purpose

This project is created for practice and learning JavaScript basics, especially for understanding Math.random(), event handling, and dynamic UI updates.
